# «Волна» на Linux-сервере (VPS): установка одной командой

Что получится: `https://voice.example.com` — адрес без порта, без предупреждений о сертификате,
участникам нужны только ссылка и пароль. Приложение поднимается само после перезагрузки сервера.

Нужно: VPS с Ubuntu 22.04/24.04 (2 ядра, 2 ГБ — обычно 3–5 $ в месяц) и домен.

> Если все участники в одной сети, сервер не нужен: хватит компьютера с `start.cmd`.
> См. README, раздел 7.

---

## Что подготовить (5 минут)

1. **VPS** с Ubuntu 22.04 или 24.04. Запишите IP-адрес.
2. **Домен**: у регистратора добавьте запись

```
Тип: A    Имя: voice    Значение: <IP вашего VPS>    TTL: 300
```

3. **Порты в панели хостинга** (там отдельный «сетевой экран», он не связан с файрволом системы):

| Порт | Протокол | Зачем |
|---|---|---|
| 443 | TCP | Приложение (адрес без порта) |
| 7881 | TCP | Резервный путь медиа, если UDP закрыт |
| 7882–7892 | UDP | Голос и демонстрация экрана |
| 3478 | UDP/TCP | TURN: нужен тем, кто за строгим NAT (симметричный, CGNAT) |
| 50000–51000 | UDP | Порты релея TURN |
| 80 | TCP | Только на время выпуска сертификата |

## Установка

```
scp volna-voice-app-linux.tar.gz root@<IP сервера>:/root/
```

На сервере:

```
cd /root
mkdir -p volna && tar -xzf volna-voice-app-linux.tar.gz -C volna --strip-components=1
cd volna
chmod +x *.sh
sudo ./install-vps.sh
```

Скрипт спросит домен и e-mail — и дальше делает всё сам. Занимает 3–5 минут.

Можно и без вопросов, одной строкой:

```
sudo ./install-vps.sh --domain voice.example.com --email me@example.com
```

### Что именно делает установщик

1. Ставит `curl`, `tar`, `certbot` (если их нет).
2. Проверяет, что домен уже указывает на этот сервер (иначе предупредит и предложит варианты).
3. Настраивает файрвол `ufw` — и, если он был выключен, включает его, **предварительно разрешив SSH**.
4. Скачивает портативный Node.js и голосовой сервер LiveKit, ставит библиотеки (~60 МБ, один раз).
5. Выпускает сертификат Let's Encrypt (нужны свободный и открытый порт 80 и настроенный домен).
6. Включает режим сервера: адрес без порта, `use_external_ip`, TURN выключен.
7. Создаёт службу systemd `volna` — автозапуск при загрузке и автоперезапуск при сбое.
8. Прописывает хук: после продления сертификата служба перезапускается автоматически.

В конце печатает адрес и **пароль комнаты**.

## Проверка (обязательно)

Проверяйте **с телефона через мобильный интернет**, не с сервера и не по Wi-Fi:

1. Откройте `https://voice.example.com`
2. Введите имя, пароль комнаты, нажмите «Войти в комнату».
3. Разрешите микрофон и нажмите «Проверить микрофон» — полоска должна реагировать на голос.

Заработало — можно звать людей. В Chrome и Edge они смогут поставить приложение
кнопкой «Установить приложение»: появится иконка в «Пуске» и отдельное окно.

Приглашать проще всего кнопкой **«Пригласить»** в окне приложения: она копирует ссылку, по которой
участник попадает в комнату автоматически (ни адрес, ни пароль вводить не нужно). В режиме сервера
в ссылку подставляется ваш домен. Адреса для ссылок обновляются при каждом запуске приложения
(файл `public/addresses.json`), поэтому после смены домена достаточно перезапустить службу.

## Полезные команды

```
systemctl status volna      # состояние службы
journalctl -u volna -f      # журнал в реальном времени
./start.sh --stop           # остановить
./start.sh                  # запустить снова
sudo ./install-vps.sh --cert-only        # выпустить/перевыпустить сертификат
sudo ./install-autostart.sh --remove     # отключить автозапуск
export PATH="$PWD/runtime/node/bin:$PATH"
node server/setup.js --rotate-password   # сменить пароль комнаты
```

Журналы приложения: `run/livekit.out.log`, `run/server.out.log`.

## Если что-то не работает

**Домен не открывается**
Проверьте `nslookup voice.example.com` — должен вернуть IP сервера, и что порт 443 открыт
в панели хостинга.

**Сертификат не выпустился**
Установщик скажет об этом и продолжит с самоподписанным (участники один раз нажмут
«Дополнительно» → «Перейти на сайт»). Причины: домен ещё не указывает на сервер, порт 80
закрыт у провайдера или занят. Подробности: `/tmp/volna-certbot.log`.
Когда домен заработает, выполните: `sudo ./install-vps.sh --cert-only`.

**Порт 443 занят**
Обычно это nginx или apache. Остановите их либо поставьте приложение на другой порт:
`sudo ./install-vps.sh --port 8443` (адрес станет с портом).

**Участник не подключается, «нет связи»**
Почти всегда закрыт UDP 7882–7892 у провайдера. Проверьте панель хостинга и `ufw status`.

**Нужен ещё и прямой TURN (для самых строгих сетей)**
`sudo ./install-vps.sh --with-turn` — тогда приложение переедет на порт 8443, а TURN/TLS
займёт 443. Адрес станет `https://voice.example.com:8443`.

**Хочу вернуться в локальный режим (без домена)**

```
export PATH="$PWD/runtime/node/bin:$PATH"
node server/setup.js --mode lan
./start.sh
```

## Ручная установка по шагам

Если хотите контролировать каждый шаг — те же действия вручную:

```
chmod +x *.sh
./firewall.sh                  # порты (от root)
./start.sh                     # скачает Node.js, LiveKit, библиотеки и запустит всё
./start.sh --stop              # остановить перед настройкой сертификата

apt-get install -y certbot
certbot certonly --standalone -d voice.example.com --agree-tos -m your@example.com --non-interactive

export PATH="$PWD/runtime/node/bin:$PATH"
node server/make-public.js --domain voice.example.com \
  --cert /etc/letsencrypt/live/voice.example.com/fullchain.pem \
  --key /etc/letsencrypt/live/voice.example.com/privkey.pem \
  --port 443 --no-turn
node server/setup.js

sudo ./install-autostart.sh    # автозапуск
```

Ключ `--no-turn` нужен потому, что порт 443 занят самим приложением; без него TURN/TLS
займёт 443, а приложение переедет на 8443 (тогда используйте `--port 8443` и уберите `--no-turn`).
