# Волна — голосовая связь для своей группы

Лёгкое приложение для голосового общения на 15–20 человек (с запасом до 25) с демонстрацией экрана.
Сделано по принципу Discord: качество звука держится за счёт того, что потоки маршрутизирует
отдельный сервер (LiveKit SFU), а не сами участники.

- **Для владельца (хост):** запускается на одном компьютере с Windows двойным кликом.
- **Для остальных:** просто открывают ссылку в браузере — ничего устанавливать не нужно.

---

## 1. Быстрый старт на Windows

1. **Распакуйте папку** в удобное место (например, `C:\Волна`). Запускать прямо из архива не нужно.
2. **Запустите приложение**: двойной клик по `start.cmd`.

При первом запуске скрипт сам скачает всё необходимое — портативный Node.js и голосовой сервер
LiveKit (около 60 МБ, интернет нужен только в этот раз), установит библиотеки, создаст сертификат
и конфигурацию, поднимет оба сервера, напечатает адрес с паролем и откроет окно приложения.
Права администратора для этого не нужны: если Node.js уже установлен в системе, используется он.
3. **Разрешите подключения** (один раз, нужны права администратора):
   правый клик по `firewall.cmd` → «Запуск от имени администратора» → подтвердить.
   Без этого шага приложение будет работать только на этом компьютере.

Чтобы запускать было удобнее, выполните `create-shortcut.cmd` — на рабочем столе появятся два ярлыка:
«Волна» (запускает сервер и открывает окно приложения, без окна консоли) и «Волна — остановить».
Запущенное с ярлыка окно само входит в комнату: поля уже заполнены, нужно только при желании
поправить имя (или нажать «Отменить» и войти вручную).

Повторный запуск ярлыка, когда приложение уже работает, ничего не перезапускает — только открывает
новое окно, поэтому никого не выкидывает из комнаты.

В консоли появится примерно такое:

```
  Приложение запущено:   https://localhost:8443
  Для других устройств:  https://192.168.1.5:8443
  Пароль комнаты:        volna-XXXX
```

### Как подключить остальных

Нажмите в окне приложения кнопку **«Пригласить»** — откроется готовое приглашение со ссылкой и кнопками
копирования. Отправьте его в мессенджер: участнику достаточно открыть ссылку, приложение подключится
само — ни пароль, ни адрес вводить не нужно, имя подставится автоматически.

Что делает такая ссылка:

- участник видит экран «Вас пригласили в комнату …» и обратный отсчёт, во время которого можно поменять имя;
- пароль комнаты внутри ссылки, но в адресной строке он не остаётся: приложение сразу его очищает;
- ссылка строится по сетевому адресу компьютера (а не по `localhost`), поэтому работает у других;
- если окно «Волны» уже открыто, второе окно с приглашением передаст комнату ему — подключится и оно;
- в приложении есть переключатель «Входить автоматически при запуске» — по умолчанию включён, поэтому
  следующее открытие приложения (например, с ярлыка или из панели задач) тоже войдёт в ту же комнату.

Если участник хочет отдельный значок на рабочем столе, есть два пути:

- он открывает ссылку и в меню браузера выбирает «Установить приложение» (Edge: «Приложения» →
  «Установить этот сайт как приложение»);
- либо вы сами выполните `create-shortcut.cmd -InviteUrl "<ссылка из кнопки «Пригласить»>"`: рядом появится
  файл `Волна — приглашение.url`, который можно просто переслать — двойной клик по нему откроет комнату.

При первом входе браузер предупредит о самоподписанном сертификате — нужно нажать
«Дополнительно» → «Перейти на сайт». Это делается один раз на каждом устройстве.
Если на компьютере хоста предупреждение мешает (окно появляется при каждом чистом запуске),
его можно убрать: запустите `trust-cert.cmd` — сертификат добавится в личное хранилище вашей
учётной записи (права администратора не нужны). Отменить: `trust-cert.cmd -Remove`.
У остальных участников предупреждение останется, пока у приложения не появится домен
с настоящим сертификатом (раздел 7).

Рекомендуем сразу нажать «Проверить микрофон». Если доступа к микрофону нет (или его нет вообще),
войти всё равно можно: приложение подключится и покажет предупреждение «Микрофон выключен» —
нажатие на эту строку пробует включить его заново.

### Установка как приложения на Windows

В архиве есть папка `desktop` — это настольная версия «Волны» (на движке Electron):

1. Запустите `desktop\install-desktop.cmd` (один раз — докачает движок окна, ~150 МБ).
2. В «Пуск» и на рабочем столе появится **«Волна»** — обычное приложение Windows: своё окно,
   без адресной строки и вкладок, своя иконка. Двойной клик — и вы в комнате.
3. Удалить: `desktop\install-desktop.cmd -Remove` (с ключом `-Purge` убирается и скачанный движок).

Что делает настольная версия: сама поднимает сервер, сама входит в комнату, при закрытии окна
останавливает сервер (если запустила его сама). Меню окна на русском: вход в комнату заново,
что показывать при демонстрации (весь экран или конкретное окно), папка приложения, журналы,
масштаб, проверка браузера и связи, «О программе».

Альтернативы без установки (как раньше): окно браузера в режиме приложения (ярлык «Волна» от
`create-shortcut.cmd`) или кнопка «Установить приложение» в самом браузере.

## 2. Что умеет

| Возможность | Описание |
|---|---|
| Голос | Opus 48 кГц, эхоподавление, шумоподавление, автогромкость, устойчивость к потерям пакетов (DTX/RED) |
| Режимы звука | «Речь» 24 кбит/с · «Высокая чёткость» 96 кбит/с · «Музыка» стерео 128 кбит/с |
| Демонстрация экрана | 720p / 1080p / 1080p60, с системным звуком, видно только в комнате |
| Участники | Подсветка говорящего, индикатор качества связи, индивидуальная громкость каждого |
| Управление | Микрофон, «оглушить всё», режим рации (Push-to-talk), горячие клавиши |
| Комнаты | Любое количество комнат по названию, вход по паролю, до 25 человек в комнате |
| Настольное приложение | Своё окно без браузерной строки и вкладок, значок в «Пуск», иконка в панели задач (`install-desktop.cmd`) |
| Друзья | Список своих людей: добавить из комнаты одной кнопкой, позвать лично, зайти в комнату друга |
| Подкомнаты | Внутри комнаты — свои подкомнаты: отдельная связь и отдельный чат у каждой (например, «игры», «переговоры») |
| Текстовая комната | Отдельная комната «Общая переписка»: только текст, без микрофона и звука |
| Без персональных данных | Нет регистрации, почты и телефонов; анонимный вход, кнопка «Забыть всё на этом устройстве», справка в `PRIVACY.md` |
| Стриминг игр | Демонстрация экрана с профилем для игр: до 1440p, 60 кадров/с, приоритет плавности и системный звук |
| Свои комнаты | Список комнат с числом участников, кнопка «Создать» и быстрый переход между комнатами прямо из меню |
| Чат комнаты | Текстовые сообщения во время звонка (внутри комнаты), счётчик непрочитанных |
| Главное меню | Шестерёнка во время звонка: звук, микрофон, комнаты, чат, выход — с возвратом в комнату по Escape |
| Шумоподавление | Отсекает гул, шипение и щелчки в паузах: в комнату уходит только речь (фильтр низов + шумовой затвор) |
| Приглашение | Ссылка-приглашение: участник подключается сам, без пароля и названия комнаты |
| Повторный вход | Выход и повторный вход сколько угодно раз; неудачная попытка не мешает следующей |
| Восстановление | Автоматическое переподключение при обрыве сети |

Горячие клавиши: **M** — микрофон, **D** — звук (оглушить), **V** — рация (удерживать, если включена).

## 3. Файлы

```
voice-app/
├─ start.cmd            ← запуск одним кликом (скачает всё необходимое)
├─ stop.cmd             ← остановить приложение
├─ open-app.cmd         ← открыть только окно приложения (сервер уже запущен)
├─ firewall.cmd         ← открыть порты (от администратора)
├─ create-shortcut.cmd  ← ярлыки на рабочем столе (можно с ключом -InviteUrl для участника)
├─ desktop\             ← настольная версия: своё окно приложения (install-desktop.cmd)
├─ install-autostart.cmd ← автозапуск при включении компьютера (для сервера)
├─ trust-cert.cmd       ← (необязательно) убрать предупреждение браузера о сертификате
├─ QUICKSTART.txt       ← короткая инструкция для того, кому вы передаёте приложение
├─ VPS-SETUP.md         ← как поднять на сервере (VPS) и работать через интернет
├─ SCENARIOS.md         ← два сценария целиком: локально на Windows и сервер на Linux-VPS
├─ install-vps.sh       ← автоматическая установка на Linux-сервер (одна команда)
├─ LINUX-VPS.md         ← руководство для Linux-сервера
├─ config.json          ← настройки: порт, пароль комнаты, лимит участников (создаётся при запуске)
├─ server/              ← веб-сервер: отдаёт интерфейс, выдаёт токены доступа
├─ public/              ← сам интерфейс приложения
│  ├─ app.js            ← комнаты, звук, демонстрация экрана
│  ├─ entry.js          ← вход: ссылки-приглашения и защита повторного входа
│  ├─ addresses.json    ← адреса для ссылок-приглашений (создаётся при запуске)
│  └─ selftest.html     ← страница самопроверки браузера
├─ livekit/             ← голосовой сервер livekit-server.exe и его конфиг
├─ runtime/             ← Node.js, скачанный автоматически (появляется при первом запуске)
├─ certs/               ← самоподписанный сертификат для HTTPS
└─ run/                 ← журналы и идентификаторы запущенных процессов
```

Удаление: остановите приложение и удалите папку `voice-app`. Больше ничего в системе не остаётся.

## 4. Настройки

Все параметры — в `config.json` (создаётся при первом запуске):

- **порт** — по умолчанию 8443;
- **пароль комнаты** — показывается в консоли при запуске;
- **лимит участников** — по умолчанию 25;
- **название сервера** — то, что видно в интерфейсе.

Сменить пароль комнаты: `node server\setup.js --rotate-password`
Применить настройки: перезапустить `start.cmd`.

Внутри приложения (шестерёнка — это **главное меню** во время звонка; закрывается клавишей Escape).
Меню разбито на вкладки: **Звук**, **Комнаты**, **Люди**, **Ещё**.

- **Звук** — микрофон, режим звука, шумоподавление, качество демонстрации, профиль для игр, рация;
- **Комнаты** — активные комнаты, свои комнаты («Создать»), **подкомнаты** внутри текущей комнаты
  и отдельная **«Общая переписка»** (только текст, микрофон там выключен автоматически);
- **Люди** — друзья: добавить по имени, «Позвать» (личное приглашение) или «Зайти» к нему;
- **Ещё** — чат комнаты, «Пригласить», **«Завершить звонок»**, **анонимный вход** и кнопка
  **«Забыть всё на этом устройстве»**.

Имя: на компьютере, где запущено приложение (адрес `localhost`), по умолчанию подставляется
**Admin** — это хост. На остальных машинах имя подставляется из прошлого входа (в анонимном
режиме — каждый раз новое).

## 5. Требования

**Хост (компьютер, где запущено):** Windows 10/11, 2 ядра, 2–4 ГБ свободной памяти,
исходящий канал от 20 Мбит/с. Голос на 20 человек занимает примерно 2–4 Мбит/с,
демонстрация 1080p добавляет около 3 Мбит/с на каждого зрителя.

**Участники:** современный браузер (Chrome, Edge, Firefox, Safari) на Windows, macOS, Linux
или телефоне. Наушники — очень желательны.

## 6. Порты

| Порт | Протокол | Зачем | Нужен снаружи |
|---|---|---|---|
| 8443 | TCP | Интерфейс и сигналинг (HTTPS) | Да |
| 7882–7892 | UDP | Голос и экран | Да |
| 7881 | TCP | Резервный путь медиа, если UDP закрыт | Да |
| 7880 | TCP | Сам LiveKit | Нет (только локально) |

В локальной сети достаточно `firewall.cmd`. Если Windows пометил вашу сеть как «общедоступную»
(частый случай для новых подключений), скрипт спросит, разрешить ли подключения и в ней — для дома
и офиса отвечайте «д». Для доступа из интернета нужен проброс этих портов на роутере
(или размещение на сервере, см. следующий раздел).

## 7. Выход в интернет (необязательно)

**Нужен ли отдельный сервер?** Нет, если все в одной локальной сети: сервером работает ваш
компьютер, остальные подключаются ссылкой. Отдельный сервер (VPS) нужен, когда люди находятся
в разных местах и вы не хотите держать свой компьютер включённым: приложение один раз ставится
на удалённую машину, а всем остальным — включая вас — остаётся только ссылка.

### Вариант А. Домашний компьютер + проброс портов
Пробросьте на роутере TCP 8443, TCP 7881 и UDP 7882–7892 на этот компьютер
и разрешите профиль «Публичная сеть» (см. `firewall.ps1`). Минус: IP-адрес дома меняется,
и останется предупреждение о сертификате.

### Вариант Б. Сервер (VPS) + домен — правильный путь

Windows-сервер: пошаговая инструкция в **VPS-SETUP.md**.
Linux-сервер: установка одной командой — **LINUX-VPS.md**, `sudo ./install-vps.sh`.

Кратко (путь для Windows-сервера):

1. Возьмите минимальный VPS (2 vCPU / 2 ГБ) и домен, например `voice.example.com`.
2. Один раз запустите приложение на сервере (`start.cmd`) — создастся `config.json`.
3. Получите бесплатный сертификат Let's Encrypt (например, программой win-acme)
   и включите режим сервера:

```
node server\make-public.js --domain voice.example.com --cert C:\certs\voice.example.com-chain.pem --key C:\certs\voice.example.com-key.pem
node server\setup.js
```

4. Запустите `start.cmd` и включите автозапуск: `install-autostart.cmd` (от администратора).
   Адрес вида `https://voice.example.com:8443` откроется без предупреждений о сертификате,
   приложение поднимется само после перезагрузки сервера, заработает TURN для участников
   за строгими сетями.

## 8. Если что-то не работает

**Не слышно других / тишина**
Проверьте, что в браузере разрешён микрофон (значок замка в адресной строке → «Микрофон» → «Разрешить»),
и нажмите на экране входа «Проверить микрофон». Если полоска не двигается — микрофон занят
другой программой или выбран не тот вход в настройках Windows.

**Проверить браузер целиком**
Откройте `https://<адрес>:8443/selftest.html` — страница по пунктам проверит микрофон, доступ
к серверу, вход в комнату и публикацию звука. Удобно, когда «у одного человека не работает».

**Участник не подключается, «нет связи»**
Чаще всего закрыт UDP: проверьте `firewall.cmd` и проброс портов. Приложение автоматически
попробует запасные пути (TCP), но UDP предпочтительнее для качества.

**Эхо и свист**
Наденьте наушники или включите «Оглушить» (клавиша D) для тех, кто рядом с колонками.

**Браузер предупреждает о сертификате**
Это нормально для локальной сети: нажмите «Дополнительно» → «Перейти на сайт». Предупреждение
исчезнет, если использовать домен с настоящим сертификатом (раздел 7). На компьютере хоста
предупреждение можно убрать сразу: `trust-cert.cmd` (отменить — `trust-cert.cmd -Remove`).

**Ярлык «Волна» открыл окно с ошибкой сертификата**
Это то же предупреждение, только в режиме приложения: нажмите «Дополнительно» →
«Перейти на localhost (небезопасно)». Чтобы больше не появлялось — `trust-cert.cmd`.

**Пригласили человека, а ссылка не подключается**
Проверьте адрес в самой ссылке: он должен быть сетевым (`https://192.168.…`), а не `localhost`.
Если там `localhost` — приложение запущено не через `start.cmd`; перезапустите его через `start.cmd`,
и адрес в приглашении обновится. Ещё проверьте, что приложение работает и порт открыт `firewall.cmd`.
Проверить свой браузер целиком: `https://<адрес>:8443/selftest.html`.

**Участник подключился, но его не слышно**
В комнате у него должно быть предупреждение «Микрофон выключен» — значит браузер не дал доступ
к микрофону. Нужно нажать на эту строку (приложение попробует включить микрофон снова) или
разрешить микрофон значком замка в адресной строке.

**Не слышно звук демонстрации экрана**
Системный звук передаётся только из Chrome и Edge в Windows и только если галочка
«Поделиться звуком системы» включена в окне выбора экрана.

**Нет звука в комнате вообще**
Если вверху появилась полоса «Браузер заблокировал звук» — нажмите «Включить звук».
Политика браузеров требует одного клика перед воспроизведением.

**Порт занят**
Закройте прошлый запуск (Ctrl+C в окне или `stop.ps1`) либо смените порт в `config.json`.

## 9. Безопасность и приватность

- Всё работает на вашем оборудовании: никаких аккаунтов, облаков и сторонних серверов.
- Медиапотоки шифруются (DTLS-SRTP), интерфейс отдаётся по HTTPS.
- Вход по паролю комнаты; токен доступа живёт 12 часов; есть ограничение на число попыток входа.
- Токен выдаётся только на вход в комнату — администрирования сервера через него нет.
- Пароль лучше менять перед сменой состава группы: `node server\setup.js --rotate-password`.
- **Персональные данные не собираются:** нет регистрации, почты, телефонов и документов;
  история чата не сохраняется ни в браузере, ни на сервере. Сам вход можно сделать полностью
  анонимным (главное меню → «Ещё» → «Анонимный вход»), а всё сохранённое стирается кнопкой
  «Забыть всё на этом устройстве». Подробности — в `PRIVACY.md`.

## 10. Как это устроено (для любопытных)

```
участники (браузеры) ──HTTPS/WSS→ веб-сервер «Волны» ──прокси сигналинга──→ LiveKit SFU
                       └────────────── голос и экран по WebRTC (UDP) ──────────────┘
```

Голосовые потоки не смешиваются и не записываются: сервер лишь пересылает пакеты.
Приоритет отдан качеству звука, поэтому в настройках по умолчанию включён режим
«Высокая чёткость» (96 кбит/с) — заметно чище телефонного качества при небольшом трафике.
