ВОЛНА — голосовая связь. Короткая инструкция.

ЧТО ЭТО
Программа для голосового общения на 15-20 человек с демонстрацией экрана.
Один компьютер запускает "сервер", все остальные просто открывают ссылку в браузере.
Ничего устанавливать никому, кроме этого компьютера, не нужно.


ЗАПУСК — ТРИ ШАГА

1. Распакуйте эту папку в удобное место, например C:\Волна
   (не запускайте прямо из архива — распакуйте)

2. Двойной клик по start.cmd

   При первом запуске программа сама скачает всё необходимое:
   • Node.js (~30 МБ) — если его нет в системе, права администратора не нужны
   • голосовой сервер LiveKit (~30 МБ)
   • библиотеки приложения (~15 МБ)
   Затем создаст сертификат, запустится и откроет окно приложения.
   Интернет нужен только в этот первый раз.

3. Разрешите подключения: правый клик по firewall.cmd →
   "Запуск от имени администратора" (нужно один раз).
   Без этого к вам не смогут подключиться другие устройства.
   Если скрипт спросит про "общедоступную" сеть — для дома и офиса отвечайте "д".

Чтобы запускать было удобнее: запустите create-shortcut.cmd —
на рабочем столе появятся два ярлыка: "Волна" (запуск, без окна консоли)
и "Волна — остановить". Запущенное с ярлыка окно само входит в комнату.
Если ярлык запустить повторно, пока приложение уже работает, оно просто
откроет новое окно — никого из комнаты не выдаёт.


ЧТО СООБЩИТЬ ОСТАЛЬНЫМ

Нажмите в приложении кнопку "Пригласить" и отправьте полученное приглашение
в мессенджер — в нём уже есть ссылка, по которой участник подключается сам,
без ввода адреса и пароля. Если удобнее по старинке, в чёрном окне написано:

  Приложение запущено:   https://localhost:8443
  Для других устройств:  https://192.168.х.х:8443
  Пароль комнаты:        volna-XXXX

Тогда отправьте им ссылку "Для других устройств" и пароль.

При первом входе браузер покажет предупреждение о сертификате —
нужно нажать "Дополнительно" → "Перейти на сайт" (это один раз на каждом устройстве).
Кнопка "Проверить микрофон" на экране входа помогает убедиться, что вас слышно.
Если микрофона нет или доступ запрещён, войти всё равно можно — приложение
подключится и покажет предупреждение "Микрофон выключен".

Внутри комнаты есть главное меню (шестерёнка) с вкладками Звук / Комнаты / Люди / Ещё:
микрофон и шумоподавление, комнаты и подкомнаты (своя связь и чат), друзья, чат комнаты,
анонимный вход и кнопка "Забыть всё". Закрыть меню — Escape.
Звонок завершает красная кнопка с телефонной трубкой справа от кнопки настроек
(то же есть в меню — "Завершить звонок").
Есть отдельная комната "Общая переписка" — только текст, без звука (история не сохраняется).
Для показа игры выберите в меню профиль с отметкой "плавно",
а в настольном приложении можно ещё указать, что показывать: весь экран или окно с игрой.

Ярлык для участника: create-shortcut.cmd -InviteUrl "<ссылка из приглашения>"
рядом появится файл "Волна — приглашение.url" — его можно просто переслать.


ЕСЛИ НУЖНО РАБОТАТЬ ЧЕРЕЗ ИНТЕРНЕТ (не из одной сети)

Вариант 1 — ваш компьютер как сервер:
  на роутере нужно пробросить порты TCP 8443, TCP 7881 и UDP 7882-7892
  на этот компьютер; компьютер должен быть включён.

Вариант 2 (рекомендуется для компании в разных городах) — поставить на сервер (VPS):
  тогда ни у кого, включая вас, ничего не установлено, компьютер выключать можно,
  и предупреждение о сертификате исчезнет (домен + бесплатный сертификат Let's Encrypt).
  Пошаговая инструкция — в файле VPS-SETUP.md.


ЧТО ЛЕЖИТ В ПАПКЕ

  start.cmd           — запуск (двойной клик)
  desktop\install-desktop.cmd — установить приложение с окном (значок в «Пуск»)
  stop.cmd            — остановить приложение
  open-app.cmd        — открыть только окно (если сервер уже работает)
  firewall.cmd        — открыть порты (от администратора)
  create-shortcut.cmd — создать ярлыки на рабочем столе
  README.md           — полная инструкция, решение проблем
  SCENARIOS.md        — два сценария: локально на Windows и сервер на Linux-VPS
  config.json         — настройки (создаётся при первом запуске)
  runtime\            — Node.js, скачанный автоматически
  livekit\            — голосовой сервер
  run\                — журналы работы


КАК УДАЛИТЬ

Остановите приложение и удалите эту папку целиком.
Больше ничего в системе не остаётся: установки в реестр не выполняется.
