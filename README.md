# «Волна» — голосовая связь и демонстрация экрана

Self-hosted голосовая комната на 15–20 человек: голос, демонстрация экрана (в том числе игр),
подкомнаты, чат, друзья и текстовые комнаты. Ядро — открытый LiveKit (SFU), сервер — Node.js,
клиент — веб-страница и настольное приложение для Windows.

Никаких облаков, аккаунтов и платных API: всё работает на вашем компьютере или вашем сервере.

## Что в репозитории

```
voice-app/                 само приложение
  server/                  HTTPS-сервер: статика, токены, прокси сигналинга LiveKit
  public/                  клиент: app.js (комнаты и звук), entry.js (вход, меню, чат, приватность)
  desktop/                 настольное приложение (Electron): своё окно без браузерной строки
  start.cmd / start.sh     запуск (Windows / Linux)
  install-vps.sh           установка на Linux-VPS одной командой
  README.md                полная инструкция для хоста
  SCENARIOS.md             два сценария работы: локально и на VPS
  PRIVACY.md               приватность: что хранится, а что нет
  PROJECT-HANDOVER.md      техническая документация для разработчика
tools/                     тестовый драйвер (headless Chrome, 25 сценариев)
deploy/                    скрипт развёртывания на VPS и план бесплатного хостинга
ОТЧЁТ-О-ДОРАБОТКЕ.md       что и как проверялось
```

## Быстрый старт (Windows)

1. Распаковать `voice-app` в удобное место (например, `C:\Волна`).
2. Двойной клик по `start.cmd` — первый запуск скачает Node.js и голосовой сервер,
   создаст сертификат и конфигурацию, поднимет сервер и откроет окно.
3. `firewall.cmd` от имени администратора — открыть порты для других устройств.
4. `create-shortcut.cmd` — ярлыки на рабочем столе.
5. `desktop\install-desktop.cmd` — установить настольное приложение (своё окно, значок в «Пуск»).

Приглашение участникам — кнопкой «Пригласить» в приложении: ссылка уже содержит адрес и пароль,
подключение происходит автоматически.

## Быстрый старт (Linux-VPS)

```bash
mkdir -p volna && tar -xzf volna-voice-app-linux.tar.gz -C volna --strip-components=1
cd volna && chmod +x *.sh && sudo ./install-vps.sh --domain voice.example.com --email me@example.com
```

Установщик поставит пакеты, настроит файрвол, скачает Node.js и LiveKit, выпустит сертификат
Let's Encrypt, включит режим сервера и создаст службу systemd с автозапуском.

## Чего в репозитории нет

Секретов и машинозависимых файлов: `config.json` (пароль комнаты), `certs/` (ключ сертификата),
`livekit/livekit.yaml` (API-ключи SFU), `public/addresses.json` (адреса этой машины), а также
скачанных движков (`node_modules`, `livekit-server.exe`). Всё это создаётся при первом запуске
и перечислено в `.gitignore`.

## Проверено

25 автоматических сценариев (`tools/volna-driver.mjs`): вход, повторный вход, вход без микрофона,
ссылки-приглашения, два окна, комнаты и подкомнаты, чат, друзья, меню, шумоподавление,
текстовая комната, приватность, завершение звонка. Настольное приложение проверено отдельно
(`tools/electron-check.mjs`), включая показ экрана на 60 кадрах/с.
