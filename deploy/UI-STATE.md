# Состояние интерфейса «Волны» (рабочая памятка)

Дата: 20.10.2026. Нужна, чтобы не потерять договорённости при пересборках.

## Раскладка комнаты

- **Верхняя панель:** логотип + **Volna** (титул страницы), справа счётчик участников и «Пригласить».
  Кнопки «Чат» больше нет — чат виден всегда.
- **Левая колонка:** заголовок «Голосовые комнаты», список каналов, ниже «Участники».
  Отдельной строки с названием комнаты нет.
- **Список каналов:** `▣ Main` — текущая комната, у неё справа кнопка **＋** (создать подкомнату).
  Ниже вложенные `└ Subroom 1`, `└ Subroom 2` … с отступом и линией.
- **Центр:** сцена с артом, внизу — **чат во всю ширину** (без рамки, только линия сверху).
- **Низ:** кнопки микрофон / звук / демонстрация / шумоподавление / завершить.

- Фон `#050605`, акцент — кислотный лайм `#8EFF03`, панели полупрозрачные (стекло).

- Полосы прокрутки переопределены (узкие, скруглённые, лаймовые).

## Фоны

- `public/bg/kadran.jpg` — арт комнаты (арка с рунами).

  Оба арта оригинальные, сгенерированы для проекта (не ассеты Valve).

## Названия комнат

- Внутренние: `main`, подкомнаты — `main--<имя>`.
- Отображение: `Main`, `Subroom N` (если имя не задано) или введённое имя как есть.
- Переименование — двойной клик или ✎, хранится локально (alias).

## Звуки

- Выход участника — один тон пониже.
