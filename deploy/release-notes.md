# Волна 1.1 — сборки для Windows и Linux

Голосовая комната на 15–20 человек с демонстрацией экрана: LiveKit (SFU) + Node.js,
клиент — веб-страница и настольное приложение для Windows.

## Что нового в 1.1

- **Связь через интернет.** Клиент получает STUN-серверы и узнаёт свой внешний адрес — без этого
  соединение за NAT не устанавливалось (в 1.0 работала только локальная сеть).
- **TURN на сервере.** Для сетей, где прямое соединение невозможно (симметричный NAT, мобильный
  CGNAT, строгий корпоративный фаервол), поднимается релей coturn: `3478/udp`, `3478/tcp`,
  порты релея `50000–51000/udp`. Клиент сам выбирает релей только когда нужно.
- **Сервер останавливается вместе с приложением.** Добавлен сторож `watch-parent.ps1`:
  если окно закрылось аварийно, сервер всё равно завершается, «висящих» процессов не остаётся.
- **Безопасная остановка.** `stop.ps1` больше не убивает процессы по номеру вслепую: сначала
  проверяет, что это действительно «Волна» (путь, командная строка, порт), умеет находить
  процессы без pid-файлов и закрывает дерево процессов. Ключи: `-DryRun`, `-Quiet`, `-Pause`.
- **Меню приложения:** «Волна → Остановить сервер» — обычная кнопка вместо отдельного ярлыка.
  Ярлык «Волна — остановить» теперь создаётся только по ключу `-WithStop` (аварийный случай).
- **Документация обновлена** под новый порядок запуска и остановки.

## Быстрый старт (Windows)

1. Распаковать архив в удобное место, например `C:\Волна`.
2. `start.cmd` — первый запуск скачает Node.js и голосовой сервер (~60 МБ) и создаст конфигурацию.
3. `firewall.cmd` от имени администратора — открыть порты для других устройств.
4. `create-shortcut.cmd` — ярлык «Волна» (аварийный «Волна — остановить» — с ключом `-WithStop`).
5. `desktop\install-desktop.cmd` — настольное приложение (своё окно, значок в «Пуск»).

Приглашение — кнопкой «Пригласить» в приложении: участник открывает ссылку и попадает в комнату сам.
Закрыли окно — сервер остановился сам; принудительно — меню «Волна → Остановить сервер».

## Быстрый старт (Linux-VPS)

```bash
mkdir -p volna && tar -xzf volna-voice-app-linux.tar.gz -C volna --strip-components=1
cd volna && chmod +x *.sh && sudo ./install-vps.sh --domain voice.example.com --email me@example.com
```

Установщик ставит пакеты, настраивает файрвол, скачивает Node.js и LiveKit, выпускает сертификат,
включает режим сервера без порта и создаёт службу systemd с автозапуском.

Для связи через интернет серверу нужны открытые порты: `443/tcp`, `7881/tcp`, `7882–7892/udp`.
Дополнительно для строгих сетей (симметричный NAT, мобильный CGNAT): TURN `3478/udp`, `3478/tcp`
и порты релея `50000–51000/udp`. Без TURN такие клиенты не соединятся вообще — остальные работают и так.
Установка TURN (coturn) на Ubuntu и настройка клиента описаны в `SCENARIOS.md`.

## Важно

В архивах **нет** секретов и машинозависимых файлов: `config.json` (пароль комнаты), `certs/`,
`livekit/livekit.yaml` (ключи SFU), `public/addresses.json` и бинарник `livekit-server.exe`
создаются при первом запуске. Первый запуск требует интернет.
