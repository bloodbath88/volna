# Бесплатный хостинг для «Волны»: домен и сервер

Цель: приложение работает на сервере в интернете, у участников адрес вида
`https://volna.qzz.io` — без предупреждений о сертификате, без включённого домашнего компьютера.

Важное ограничение, из которого следует всё остальное: «Волне» нужен **настоящий виртуальный
сервер с публичным IPv4** — голос и демонстрация экрана идут по **UDP 7882–7892**, плюс TCP 443
и 7881. Поэтому бесплатные PaaS-платформы (Render, Railway, Fly.io, Vercel и подобные) не подходят:
они не пропускают произвольный UDP.

---

## 1. Что реально бесплатно в 2026 году

| Вариант | Что дают | Ограничения | Подходит для «Волны» |
|---|---|---|---|
| **Oracle Cloud Always Free** | ARM Ampere: **2 OCPU / 12 ГБ** (после сокращения в 2026), плюс 2× AMD micro (1 ГБ), 10 ТБ трафика в месяц | Нужна карта для верификации (списаний на Always Free нет); ARM-ёмкость в популярных регионах часто «out of capacity» | **Да, лучший вариант** |
| **Google Cloud Free Tier** | 1× e2-micro (1 ГБ) в us-central1/us-west1/us-east1 | Бесплатные регионы только США → задержка звука из России +120–150 мс | Да, но звук будет хуже |
| AWS / Azure | 12 месяцев пробного периода | Потом платно; карта обязательна | Только как временный тест |
| Yandex Cloud / VK Cloud | Грант на 60 дней | Не «навсегда» | Только для теста |
| Дешёвый платный VPS | ~200–400 ₽/мес (2 ядра, 2 ГБ) | Платно | Самый предсказуемый вариант |

**Рекомендация:** Oracle Cloud Always Free в регионе Европы (Frankfurt/Amsterdam) — лучшее
соотношение «бесплатно + нормальная задержка + достаточно памяти». Если ARM не выдаётся —
берите AMD micro (1 ГБ хватает на комнату до 10–15 человек без тяжёлой демонстрации экрана).

## 2. Домен

**DigitalPlat FreeDomain** (`domain.digitalplat.org`, зоны `.qzz.io`, `.us.kg`, `.dpdns.org`,
`.xx.kg`, `.qd.je`) — бесплатные поддомены, но **свой DNS нужен отдельно**: в панели указываются
custom nameservers. Бесплатный DNS — Cloudflare.

Порядок:

1. Зарегистрировать в панели DigitalPlat имя, например `volna.qzz.io` (нужна почта).
2. Добавить этот домен в Cloudflare (бесплатный план) → Cloudflare выдаст пару NS.
3. Вписать эти NS в панели DigitalPlat для своего имени.
4. Дождаться активации зоны в Cloudflare (5–30 минут).
5. В Cloudflare → DNS → добавить запись:
   `A`, имя `@`, значение — **IP сервера**, TTL Auto, **Proxy выключен (серое облако)**.
   Прокси включать нельзя: он не пропускает UDP-медиа и ломает WebRTC.

Проверка: `nslookup volna.qzz.io` должен вернуть IP сервера.

### Если сертификат не выпускается

Let's Encrypt считает лимит «50 сертификатов на зарегистрированный домен в неделю». Если зона
не входит в Public Suffix List (а бесплатные зоны часто не входят), лимит общий на всю зону —
тогда приходит ошибка `too many certificates already issued`. Что делать:

- повторить через сутки (лимит скользящий), либо
- выпустить сертификат через **ZeroSSL** (тот же ACME): `certbot --server https://acme.zerossl.com/v2/DV90`,
  либо
- взять обычный домен за ~200–500 ₽/год — самый надёжный путь.

## 3. Сервер: что сделать в Oracle (10–15 минут)

1. **Регистрация** на cloud.oracle.com (Free Tier). Нужна карта (проверка личности, на Always Free
   списаний нет) и подтверждение почты.
2. **Создать инстанс**: Compute → Instances → Create.
   - Image: **Ubuntu 22.04** или **24.04** (Canonical);
   - Shape: **VM.Standard.A1.Flex** (ARM), 2 OCPU / 12 ГБ (если «out of capacity» — попробуйте
     другое Availability Domain или shape **VM.Standard.E2.1.Micro**, 1 ГБ);
   - Boot volume: 50 ГБ (в пределах бесплатных 200 ГБ);
   - **Assign a public IPv4 address: Yes**;
   - SSH-ключ: можно сгенерировать в консоли и скачать приватный ключ, либо добавить свой.
3. **Открыть порты — в двух местах.** Это главная ловушка Oracle: в консоли правила есть, а на
   самом инстансе iptables по умолчанию всё блокирует.

   **а) В консоли:** VCN → Security Lists → Default Security List → Add Ingress Rules:

   | Source | Protocol | Port |
   |---|---|---|
   | 0.0.0.0/0 | TCP | 80 |
   | 0.0.0.0/0 | TCP | 443 |
   | 0.0.0.0/0 | TCP | 7881 |
   | 0.0.0.0/0 | UDP | 7882–7892 |

   **б) На инстансе** (по SSH, от root или через sudo):

   ```bash
   iptables -I INPUT 1 -p tcp --dport 80 -j ACCEPT
   iptables -I INPUT 1 -p tcp --dport 443 -j ACCEPT
   iptables -I INPUT 1 -p tcp --dport 7881 -j ACCEPT
   iptables -I INPUT 1 -p udp --dport 7882:7892 -j ACCEPT
   netfilter-persistent save 2>/dev/null || (apt-get update -qq && apt-get install -y iptables-persistent && netfilter-persistent save)
   ```

   `install-vps.sh` дополнительно настроит `ufw` — эти правила ему не мешают, они открывают то же самое.

4. **Проверить**, что порты видны снаружи: с чужой машины `nc -vz <IP> 443` и `nc -vzu <IP> 7890`.

## 4. Что прислать мне

- IP сервера (публичный);
- пользователь SSH (`root` или `ubuntu` — на образах Oracle по умолчанию `ubuntu`);
- домен (`volna.qzz.io`);
- e-mail для Let's Encrypt;
- подтверждение, что ключ добавлен (команда ниже) и порты открыты.

Ключ добавляется одной строкой на сервере (подставьте своего пользователя):

```bash
mkdir -p ~/.ssh && chmod 700 ~/.ssh && \
echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIA/GWd3K7OegwV2Mvu0o5odqMFuRWIFfE/NUprhCpQgW volna-deploy' >> ~/.ssh/authorized_keys && \
chmod 600 ~/.ssh/authorized_keys && echo ok
```

Если пользователь не root — ему нужен `sudo` без пароля:

```bash
echo "$USER ALL=(ALL) NOPASSWD:ALL" | sudo tee /etc/sudoers.d/volna && sudo chmod 440 /etc/sudoers.d/volna
```

## 5. Что сделаю я

1. Подключусь ключом, проверю ОС и что домен указывает на этот IP.
2. Залью `volna-voice-app-linux.tar.gz` в `/opt/volna` и распакую.
3. Запущу `sudo ./install-vps.sh --domain … --email …` (пакеты, ufw, Node.js, LiveKit, сертификат,
   режим сервера без порта, служба systemd с автозапуском).
4. Проверю снаружи: `https://домен`, `/api/health`, `/selftest.html`, срок сертификата,
   что UDP-порты слушаются.
5. Пришлю адрес, пароль комнаты и отчёт; дам команду убрать мой ключ.

## 6. Чего ждать от бесплатного (честно)

- **Нет SLA.** Oracle может «усыпить»/забрать простаивающий инстанс, бесплатные зоны доменов
  иногда блокируются в отдельных сетях.
- **Один публичный IPv4** — этого достаточно, но IPv6-only инстансы для «Волны» не подойдут.
- **10 ТБ трафика** в месяц у Oracle — для голосовой комнаты это очень много, упереться сложно.
- **Сертификат придётся продлевать** — установщик ставит хук, продление автоматическое;
  если зона упрётся в лимиты Let's Encrypt, перейдём на ZeroSSL.
- **Пароль комнаты** печатается установщиком — сохраните и передайте только своим.
